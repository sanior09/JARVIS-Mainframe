## 📝 เทมเพลตสำหรับจดไอเดียใหม่ (Idea Template)
เมื่อเจ้านายมีไอเดียใหม่ สามารถบอก J.A.R.V.I.S. หรือสร้างไฟล์ `.md` ใหม่ในโฟลเดอร์นี้โดยใช้โครงสร้างดังนี้:

1. **Project Vision:** จุดประสงค์และเป้าหมายของโปรเจกต์คืออะไร
2. **Key Capabilities:** ฟีเจอร์เด่นที่ระบบต้องทำได้
3. **Architecture:** สถาปัตยกรรม เทคโนโลยี หรือเครื่องมือที่ใช้
4. **Resource & Feasibility:** การใช้ทรัพยากร (RAM, CPU, API) บนเครื่องปัจจุบัน
5. **Roadmap Phases:** แผนงานเป็นขั้นๆ (Phase 1 ถึง Phase 5)
